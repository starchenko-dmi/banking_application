# 📊 banking_application: анализатор банковских операций и финансовых рынков

**banking_application** — это Python-проект для анализа личных финансов на основе банковской выписки в Excel.  
Сервис обрабатывает операции, считает расходы по картам, определяет топ-5 транзакций, анализирует кешбэк по категориям и получает актуальные курсы валют и цены акций через внешние API.

Проект возвращает данные в формате JSON, поэтому его можно использовать как backend-часть для веб-страницы, Telegram-бота или CLI-приложения.

---

## 🚀 Возможности проекта

### 📱 Главная страница
Формирует общий финансовый отчёт:
- приветствие в зависимости от времени суток;
- расходы по банковским картам и кешбэк (1%);
- топ-5 транзакций по сумме платежа;
- актуальные курсы валют и цены акций.

### ⚙️ Сервисы
- **Выгодные категории повышенного кешбэка:** анализ транзакций за выбранные год и месяц для выявления категорий, принёсших максимальную выгоду.

### 📈 Отчёты
- **Траты по категории:** анализ динамики расходов по конкретной категории за последние 3 месяца.
- **Автоматическое сохранение:** декоратор `@report_to_file` прозрачно сохраняет результаты любых аналитических функций в JSON-файлы с временными метками.

## 🏗 Архитектурные решения

1. **Разделение получения данных и бизнес-логики**  
   Функции бизнес-логики принимают уже подготовленные данные (списки словарей или DataFrame). Это упрощает тестирование и позволяет в будущем легко заменить источник данных.
2. **Использование `pandas` для обработки табличных данных**  
   Excel-файл читается через `pandas`, даты приводятся к единому формату, операции гибко фильтруются по диапазону дат.
3. **Отказоустойчивость API (Fallback-механизм)**  
   Курсы валют получаются через Alpha Vantage. Если сервис недоступен, система автоматически переключается на резервный источник — API ЦБ РФ.
4. **Декораторы для сквозной функциональности**  
   Декоратор `report_to_file` перехватывает результат функции и сохраняет его в JSON без изменения самой бизнес-логики.

## ⚙️ Установка и настройка

### 1. Клонировать репозиторий
```bash
git clone https://github.com/starchenko-dmi/banking_application.git
cd banking_application
```

### 2. Установить зависимости
Если используется Poetry:
```bash
poetry install
poetry shell
```
Если используется pip:
```bash
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настроить переменные окружения
Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```
Добавьте ваш API-ключ (получить можно на сайте [Alpha Vantage](https://www.alphavantage.co/support/#api-key)):
```env
API_ALPHAVANTAGE=your_alphavantage_api_key_here
```

### 4. Подготовить данные
Поместите файл с банковской выпиской в папку `data/`:
```text
data/operations.xlsx
```

## 💻 Использование и запуск

Модуль `main.py` находится в корне проекта. Запуск выполняется через CLI с передачей команд и аргументов.

Посмотреть справку по всем командам:
```bash
python main.py --help
```

### 1. Главный финансовый отчёт (`main`)
Возвращает общий отчёт: карты, топ-5 транзакций, валюты, акции.

**Базовый запуск:**
```bash
python main.py main
```

**Запуск с конкретной датой и файлом:**
```bash
python main.py main --date "2020-08-25 15:30:00" --file operations.xlsx
```

**Пример вывода:**
```json
{
  "greeting": "Добрый день",
  "cards": [
    { "last_digits": "5814", "total_spent": 1262.0, "cashback": 12.62 }
  ],
  "top_transactions": [
    { "date": "21.12.2021", "amount": -1198.23, "category": "Переводы", "description": "..." }
  ],
  "currency_rates": [
    { "currency": "USD", "rate": 73.21 },
    { "currency": "EUR", "rate": 87.08 }
  ],
  "stock_prices": [
    { "stock": "AAPL", "price": 150.12 }
  ]
}
```

---

### 2. Отчёт по кешбэку (`cashback`)
Возвращает JSON с суммой кешбэка по категориям за выбранный месяц и год.

**Запуск:**
```bash
python main.py cashback --year 2020 --month 11
```

**Пример вывода:**
```json
{
    "Супермаркеты": 450.5,
    "АЗС": 120.0,
    "Развлечения": 300.0
}
```

---

### 3. Траты по категории (`spending`)
Возвращает траты по заданной категории за последние 3 месяца от указанной даты.

**Базовый запуск:**
```bash
python main.py spending --category "Супермаркеты" --date "2020-04-01"
```

**Запуск с сохранением результата в JSON-файл:**
```bash
python main.py spending --category "Супермаркеты" --date "2020-04-01" --output supermarkets.json
```
*Результат будет выведен в консоль и параллельно сохранён в файл `supermarkets.json`.*

## ⚠️ Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `No module named src` | Команда запускается не из корня проекта или отсутствует `src/__init__.py`. | Перейти в корень проекта (`cd banking_application`) и убедиться в наличии `__init__.py`. |
| `FileNotFoundError` | В папке `data/` отсутствует файл `operations.xlsx`. | Положить файл в папку `data/` или указать другой через аргумент `--file`. |
| `API ключ не найден` | Отсутствует файл `.env` или в нём нет ключа `API_ALPHAVANTAGE`. | Создать `.env` и прописать ключ API. |
